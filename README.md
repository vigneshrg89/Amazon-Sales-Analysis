# 📊 Amazon Sales Data Analysis

## 📌 Project Overview

This project focuses on analyzing Amazon sales data using Microsoft Power BI to transform raw data into meaningful insights through interactive visualizations and dashboards.

The dashboard helps users understand sales performance, identify trends, and explore key business metrics to support data-driven decision-making.

## 🎯 Project Objectives

* Analyze Amazon sales performance.
* Identify sales trends and patterns.
* Present key business insights through interactive dashboards.
* Practice data visualization and business intelligence skills.

## 🛠️ Tools & Technologies

* **Microsoft Power BI** — Data visualization and dashboard development.
* **CSV** — Data source.

## 📂 Project Files

* `AmazonSalesDashboard.pbix` — Power BI project file.
* `AmazonSalesData.csv` — Dataset used for analysis.

## 📈 Key Skills Demonstrated

* Data analysis
* Data visualization
* Dashboard development
* Business intelligence
* Data-driven decision-making
